# Finance UI Demo — School Project

Static GitHub Pages / iPhone standalone web-app demo.

## Publish
1. Upload all files in this folder to the repository root.
2. GitHub repository → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main, folder: /(root).
5. Save and wait for the Pages URL.
6. Open the Pages URL in Safari.
7. Share → Add to Home Screen → Open as Web App.

The project contains a persistent school-project / UI-simulation marking and is not a bank record.

## Time behavior
The latest STB transaction is generated at current browser time minus 12 minutes.
The other "today" transactions are generated earlier in the same day.
Click the latest STB transaction to open the detail screen.
